역전파(backpropagation)는 신경망의 손실을 각 파라미터로 미분해 그래디언트를 구하는 방법입니다. 핵심은 미분의 연쇄법칙(chain rule)을 계산 그래프 위에서 효율적으로 적용하는 것뿐입니다.

순전파와 손실

각 층은 입력에 가중치를 곱하고 활성화 함수를 거칩니다. 한 층을 예로 들면 다음과 같습니다.

z = W·x + b
a = σ(z)        # σ: 활성화 함수 (ReLU, sigmoid 등)

마지막 출력과 정답으로 손실 L을 계산합니다. 우리가 알고 싶은 것은 ∂L/∂W, ∂L/∂b입니다. 이 값으로 경사하강을 하면 손실이 줄어듭니다.

연쇄법칙으로 그래디언트 전파

출력 쪽 그래디언트를 입력 쪽으로 거슬러 곱해 나갑니다. 한 층의 입력 그래디언트 δ는 다음으로 계산됩니다.

δ = (∂L/∂a) ⊙ σ'(z)      # 출력 그래디언트에 활성화 미분을 곱함
∂L/∂W = δ · xᵀ
∂L/∂b = δ
∂L/∂x = Wᵀ · δ           # 이전 층으로 넘겨줄 값

여기서 ⊙는 원소별 곱입니다. 마지막 줄 ∂L/∂x를 이전 층의 출력 그래디언트로 다시 넘기는 것이 역전파의 핵심 재귀입니다.

왜 효율적인가

  • 중복 제거: 각 노드의 미분을 한 번만 계산해 재사용하므로 비용이 순전파와 같은 차수에 머문다.
  • 국소성: 각 연산은 자기 입력/출력의 미분만 알면 되고, 전역 구조를 몰라도 된다.
  • 자동 미분: 이 규칙을 일반화한 것이 PyTorch/TensorFlow의 autograd다.

실전에서 주의할 점

층이 깊어지면 σ'(z)가 반복해서 곱해져 그래디언트가 0으로 사라지거나(vanishing) 폭발(exploding)할 수 있습니다. ReLU 활성화, 가중치 초기화(He/Xavier), 배치 정규화 등이 이를 완화합니다.

한 줄 요약: 역전파는 마법이 아니라 연쇄법칙을 계산 그래프 위에서 출력→입력 방향으로 한 번만 훑는 것이다.
