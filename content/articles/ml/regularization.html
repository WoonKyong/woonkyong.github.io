과적합(overfitting)은 모델이 훈련 데이터의 잡음까지 외워버려 새 데이터에서 성능이 떨어지는 현상입니다. 정규화(regularization)는 모델의 자유도를 적절히 제약해 일반화 성능을 끌어올리는 기법들의 묶음입니다.

과적합을 어떻게 알아채나

훈련 손실은 계속 내려가는데 검증(validation) 손실이 어느 시점부터 다시 올라간다면 과적합입니다. 반대로 둘 다 높게 머물면 과소적합(underfitting), 즉 모델이 너무 단순한 경우입니다.

  • 편향-분산 트레이드오프: 단순한 모델은 편향이 크고, 복잡한 모델은 분산이 크다. 정규화는 분산을 낮추는 쪽이다.

가중치 패널티: L2와 L1

손실에 가중치 크기 항을 더해 큰 가중치를 억제합니다.

L2:  L_total = L + λ·Σ wᵢ²      # weight decay, 가중치를 0 쪽으로 부드럽게
L1:  L_total = L + λ·Σ |wᵢ|     # 일부 가중치를 정확히 0으로 → 희소성

λ가 클수록 제약이 강해집니다. L2는 모든 가중치를 골고루 줄이고, L1은 불필요한 특성을 아예 꺼서 특성 선택 효과를 냅니다.

그 밖의 실용적 기법

  • Dropout: 학습 중 뉴런 일부를 무작위로 꺼서 특정 경로에 과의존하지 않게 한다. 추론 시에는 전부 켠다.
  • Early stopping: 검증 손실이 더 안 좋아지기 시작하면 학습을 멈춘다. 가장 싸고 효과적인 정규화다.
  • Data augmentation: 이미지 뒤집기·자르기 등으로 데이터를 늘려 모델이 본질적 패턴을 배우게 한다.
  • 배치 정규화: 분포를 안정화하면서 약한 정규화 효과도 준다.
한 줄 요약: 정규화는 모델을 일부러 조금 불편하게 만들어, 훈련 데이터 암기 대신 일반화 가능한 패턴을 배우도록 강제하는 것이다.
