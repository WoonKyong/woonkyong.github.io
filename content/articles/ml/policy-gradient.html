정책 경사(policy gradient)는 가치 함수를 거쳐 행동을 고르는 DQN 계열과 달리, 정책 π(a|s; θ)를 직접 파라미터화해 기대 보상을 최대화하도록 학습하는 강화학습 방법입니다. 연속 행동 공간이나 확률적 정책이 필요할 때 특히 유용합니다.

목표와 기본 정리

목표는 정책을 따랐을 때의 기대 누적 보상 J(θ)를 키우는 것입니다. 정책 경사 정리는 그래디언트를 다음과 같이 줍니다.

∇J(θ) = E[ ∇ log π(a|s; θ) · R ]

직관: 보상 R이 좋았던 행동의 로그 확률을 높이고, 나빴던 행동은 낮추도록 파라미터를 민다는 뜻입니다.

REINFORCE

가장 단순한 구현은 한 에피소드를 끝까지 굴린 뒤, 각 시점의 실제 리턴 G_t로 위 그래디언트를 추정합니다.

for each episode:
    rollout으로 (s, a, r) 수집
    G_t = Σ γ^k r_{t+k}            # 시점 t 이후 누적 보상
    θ ← θ + α · Σ_t ∇ log π(a_t|s_t) · G_t

문제는 G_t의 분산이 커서 학습이 출렁인다는 점입니다. 그래서 상태 가치 V(s)를 빼는 baseline을 도입해 이점(advantage) A = G − V를 쓰면 분산이 크게 줄어듭니다. 이것이 actor-critic의 출발입니다.

PPO: 안정적인 업데이트

정책을 한 번에 너무 크게 바꾸면 성능이 무너집니다. PPO(Proximal Policy Optimization)는 새 정책과 옛 정책의 확률 비 r(θ)를 일정 범위로 잘라(clip) 과도한 갱신을 막습니다.

L = E[ min( r(θ)·A,  clip(r(θ), 1−ε, 1+ε)·A ) ]
# r(θ) = π_new(a|s) / π_old(a|s)

구현이 간단하면서도 안정적이라 오늘날 가장 널리 쓰이는 알고리즘 중 하나이며, RLHF 같은 LLM 미세조정에도 사용됩니다.

한 줄 요약: 정책 경사는 "좋았던 행동의 확률을 높인다"는 한 문장이고, baseline은 분산을, PPO의 clip은 과한 갱신을 잡아 학습을 안정화한다.
